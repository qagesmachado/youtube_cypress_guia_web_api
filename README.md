# Cypress Guia WEB e API
Playlist: [Guia - Cypress Web e API](https://www.youtube.com/playlist?list=PLVQdoQTyi01hAYibssFzQRhFkt4GaW78c)

## Como instalar
- npm install cypress --save-dev
- npx cypress open

## Fez o clone do repositório?
Caso tenha feito o clone do repositório você apenas precisa digitar o comando:
- npm i
